03

The protocol

DNS gets out of almost every network

Allowed out

DNS leaves almost every network and is rarely inspected.

Relayed for you

The resolver passes any name on to the server that owns the domain.

Never cached

A repeated name never reaches the attacker, so every query needs a new name.

In our capture the client reached the tunnel server directly, on the same network segment.

04

Discovery

One domain gives itself away

  • 6 times more unique names than any other domain.
  • Its longest name is 252 bytes. DNS allows 255. The longest normal name is 103.
  • The only domain asked for NULL records.
  • Every query comes from one host, 10.0.2.30, which asks for nothing else.

Name lengths counted in bytes on the wire, not as Zeek prints them.

Four of the first frames of the session in case1.pcap.

  1. VACK

    The first answer is iodine's version acknowledgement.

  2. Version 00000502

    Decoded from the first query. It is the published protocol version.

  3. Built-in test sentences

    The German and French strings are hard-coded in iodine's client.

MITRE ATT&CK lists iodine under T1572, Protocol Tunneling.

Timeline

07

The payload

Inside the tunnel: one voice call

  • An answering machine picks up. 169 audio frames come down, 2 go up.
  • 4.5 KB up, 14.5 KB down. The upload is the call set-up.
  • Each audio frame arrives as the answer to a ping.

No sign of data theft. The same channel could carry commands or stolen files.

Decoded from case1.pcap with the iodine protocol specification.

09

Attack mechanics

What a tunnel cannot hide

Any DNS tunnel shows these

Hard to change

  • Many new names under one domain
  • Long, random-looking names
  • A steady stream of queries, even when idle
  • Answers that carry data

Only this tool, or this lab

Easy to change

  • iodine's start-up letters and VACK
  • Queries sent straight to the attacker
  • One source port, TTL 0, EDNS0

173 of the 222 tunnel queries are short pings that look normal on their own. So the detector has to judge the domain, not the single query.
